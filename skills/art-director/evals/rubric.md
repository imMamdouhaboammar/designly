# Eval Rubric

Deterministic tests cover package structure, routing, design-spec quality, and release-gate logic

They do not pretend to measure the final visual without seeing it

## Package checks

- skill trigger metadata
- SKILL length and resource discoverability
- current manifests and JSON validity
- Python syntax
- schema/template contracts
- deprecated duplicate rules removed
- arbitrary fixed RTL percentage rule removed

## Routing checks

- generate
- edit
- manipulation
- reference
- campaign
- typography-heavy
- review
- quick/director/exploration modes

## Design preflight checks

The structured Art Direction Spec is linted for

- missing primary message
- adjective-only concept
- weak hierarchy contract
- missing grid or alignment logic
- freeform composition without anchors
- excess focal points without rationale
- missing eye path
- typography-heavy exact copy not locked
- uncontrolled type-role count
- missing contrast verification plan
- style-family entropy
- effects without jobs
- effect-stack pressure

## Release-gate checks

- weighted score threshold 92
- category floors
- hard gates
- applicability-aware typography/color/brand/product/physics floors
- AI slop critical/major/minor counts
- cumulative slop pressure

## Manual visual evals

Run with an actual image-capable host

- one-second read
- thumbnail hierarchy
- squint/blur value masses
- grayscale hierarchy
- edge/tangent/crop quality
- figure-ground separation
- Arabic glyph integrity
- brand-off specificity
- effect-subtraction survival
- product fidelity
- material/light/perspective coherence
- typography craft
- color contrast
- local-edit collateral change
- campaign continuity

A deterministic PASS is necessary but not sufficient for visual release
