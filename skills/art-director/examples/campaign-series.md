# Example: Campaign Series

## User request

Create five related launch visuals that feel like one campaign without repeating the same frame

## Visual DNA

Lock

- palette roles
- type-role relationships
- spacing rhythm
- lighting family
- image treatment
- logo behavior
- product scale range

Allow controlled changes in

- camera distance
- hero action
- environment
- dominant mass
- crop
- supporting props

## Mutation plan

Asset 1: iconic product hero

Asset 2: tactile detail

Asset 3: human-use proof

Asset 4: benefit metaphor

Asset 5: offer/action resolution

## Continuity test

Place all five together

Reject if they look like one template with swapped copy or if one introduces a new style family with no campaign role
