# Example: Strict Local Edit

## User request

Change only one product cap from black to brushed silver and preserve the rest

## Edit contract

Target: cap only

Allowed change: cap color/material response

Locked: product body, label, logo, hand, background, crop, lighting direction, dimensions, and all text

Protected: every region outside the cap

## Acceptance

- silver material reacts to the existing light
- cap geometry is unchanged
- no visible collateral change outside the target
- product identity remains exact

Do not restyle or regenerate the full frame
