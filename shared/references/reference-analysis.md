# Reference Analysis

Deconstruct references into visual grammar that can be adapted without copying source-specific content

## Analyze in layers

### Strategy layer
- what appears to be the communication job
- what is the first read
- what is intentionally suppressed

### Structure layer
- grid or anchors
- visual weight
- hero scale and position
- grouping
- eye path
- crop
- negative space
- edge behavior

### Type and color layer
- type roles
- alignment
- line shape
- value hierarchy
- palette roles
- accent behavior

### Image craft layer
- camera relationship
- lighting
- depth
- materials
- texture
- manipulation
- realism/stylization

### Signature layer
- what makes the reference recognizable
- which parts are generic principles
- which parts are source-specific trade dress, campaign content, characters, or protected arrangement

## Rule extraction

Turn observation into transferable instructions

Weak

`Use this reference's style`

Better

`Use one oversized lower-frame hero, one strong vertical text anchor, broad low-frequency background, hard directional cast shadow, and a quiet secondary brand zone`

Prefer relationships and principles over copying coordinates

## Reference-ID behavior

When several references are supplied, give each a job

Example

- REF-01: hierarchy and crop
- REF-02: light character
- REF-03: material treatment
- REF-04: type density

Do not average everything together

Resolve conflicts by the job most relevant to the current brief

## Similarity control

Preserve requested functional logic while changing source-specific content, trademarked assets, protected characters, distinctive campaign copy, and unnecessarily exact arrangement when ownership is not established

When the user owns or supplies the source and asks for direct editing, preserve the requested source rather than reinterpreting it

## Reference quality check

A reference can be visually attractive and still be wrong for the current job

Reject reference behaviors that conflict with

- message hierarchy
- brand truth
- platform context
- readability
- product accuracy
- cultural fit
