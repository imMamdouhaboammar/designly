# Design Source Notes

Load this file only when the user asks for the basis of a design rule or when maintaining the skill

These sources inform principles, not a visual style preset

## WCAG 2.2

W3C Web Content Accessibility Guidelines 2.2, Success Criterion 1.4.3

- normal text target: at least 4.5:1 contrast
- large text target: at least 3:1 contrast
- logotypes are excepted from that specific criterion

Official source: https://www.w3.org/TR/WCAG22/

## Apple Human Interface Guidelines: Layout

Relevant principles

- place items to communicate relative importance
- consider language reading order, including RTL
- align components to improve scanning and organization
- adapt layout to context rather than fixing one geometry everywhere

Official source: https://developer.apple.com/design/human-interface-guidelines/layout

## Apple Human Interface Guidelines: Typography

Relevant principles

- type choices should support legibility and information hierarchy
- weight, size, and color can differentiate importance
- too many typefaces can obscure hierarchy and reduce consistency

Official source: https://developer.apple.com/design/human-interface-guidelines/typography

## Apple Design Principles

Relevant principles

- start from purpose
- simplicity removes what is unnecessary but is not identical to minimalism
- craft requires deliberate attention to detail
- principles guide tradeoffs rather than prescribing one fixed application

Official source: https://developer.apple.com/design/human-interface-guidelines/design-principles

## Material Design 3

Relevant principle

- layout structures should adapt to available space and context rather than be treated as one fixed canvas template

Official source: https://m3.material.io/
